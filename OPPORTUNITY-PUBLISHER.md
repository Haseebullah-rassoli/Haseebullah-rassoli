# Publishing and privacy

Visitors can read published opportunities and follow links to the official provider.
Applications are completed on the provider's website, not collected by this site.

The owner's separate, authenticated publishing studio stores drafts privately.
Only the selected public fields are copied here after an explicit Publish action.
Private notes and GitHub connection credentials must never be committed here.

The old GitHub Actions input-based publisher has been retired: a public repository
is not private draft storage. Do not put unpublished information into Actions,
issues, pull requests, or repository files. Public content can be copied or cached;
changing or removing it later cannot retract copies already made by others.

Every published opportunity needs an official source and application link.
Dates, funding, eligibility and country restrictions must be checked against that
source; leave unknown information explicitly marked as not stated.
