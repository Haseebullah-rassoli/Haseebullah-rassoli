# Verified Digital Hub — Phase 1

This is a static, no-build, no-fee website extension. The existing portfolio's images and three resume projects remain intact. Five navigation sections are live: About & Contact, Cybersecurity, Opportunities, Books & Tools, and Business.

## Editorial workflow
1. Verify facts against original sources. Record date, what was checked, and outstanding uncertainty.
2. Write the master article on the site. Do not claim absolute safety or label an unconfirmed case a scam.
3. Remove personal identifiers from user-submitted material before any public discussion.
4. Post brief summaries manually on the relevant social platforms and link back here.
5. Correct the master article when new information arrives.

## Community submissions
The review form uses the visitor's email app via mailto; **there is no server, automatic upload, inbox integration, or case database**. Do not request passwords, OTPs, bank details, passport copies or unredacted sensitive screenshots. Email delivery and replies are not guaranteed. The public GitHub repository must never contain private submissions.

## Publishing
Edit HTML files in GitHub and commit. GitHub Pages will deploy from the configured source branch. Add fully reviewed opportunity listings as separate HTML pages later. Do not publish unverified calls just to fill the site. Future social automation should be opt-in and require editorial approval. No paid payment flow is enabled.

## Assets
The original portfolio assets in `assets/` are reused, without deleting the original content.
