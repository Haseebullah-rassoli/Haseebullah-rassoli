# Publishing system (manual-first)

The website is the canonical source. Keep each case/opportunity as a separate reviewed article in the public content folders, and never commit raw community reports or private information.

## Review checklist
- [ ] Exact claim, date received and type of source recorded privately.
- [ ] Original primary source and official domain checked; source URL and check date recorded.
- [ ] Eligibility, funding, fees, language tests and deadlines individually verified (for opportunities).
- [ ] No false promise of 100% safety, no unsupported scam accusation, no invented data.
- [ ] Screenshots redacted; submitter not identified without explicit consent.
- [ ] Evidence label assigned to specific claim, with limitations.
- [ ] Sponsored relationship disclosed, if any, and review remains independent.
- [ ] Article proofread, links checked and last-updated date set.
- [ ] Only then write short platform-specific social captions linking to the canonical article.

## New content workflow
Copy the relevant template below to a new descriptive HTML file, replace ALL placeholder fields with checked facts, link it from the relevant category index, and commit to the draft branch. If details are unknown, write 'Not confirmed' rather than guessing. Do not publish a template as a real case or opportunity.

## Status
This branch is a draft. No cross-platform publishing automation, payment processing, secure file-upload backend or case database has been configured.
